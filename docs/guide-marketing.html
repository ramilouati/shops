Ce que le client peut faire

1. Trouver un article

  1. Ouvrir la boutique, puis Boutique.
  2. Choisir une catégorie en haut : Tout, Vestes, Robes, et les autres.
  3. Écrire un mot dans Rechercher, par exemple « robe ».
  4. Trier avec la liste : prix croissant, prix décroissant, ou nom de A à Z.

2. Voir si l’article est disponible

  1. Plus que 5 en stock (ou un autre petit nombre) : il en reste peu.
  2. Rupture : on ne peut pas l’ajouter au panier.
  3. Sinon, le bouton Ajouter au panier est actif. Après l’ajout, il devient Déjà ajouté.

3. Commander et payer à la livraison

  1. Ouvrir le panier, puis Commander.
  2. Remplir le prénom, le nom, l’adresse, la ville et le téléphone. Sur l’écran, ces champs sont encore écrits en anglais : First Name, Last Name, Street Address, Town / City, Phone.
  3. Laisser le paiement sur Paiement à la livraison.
  4. Appuyer sur Confirmer la commande.
  5. La page suivante montre le numéro, par exemple TS-1001. Le garder : il sert au suivi.

4. Utiliser un code promo et la livraison

  1. Sur la page de commande, écrire le code dans Code promo. Le code de démonstration est BIENVENUE : 10 % de réduction.
  2. Le total se met à jour tout seul : sous-total, réduction, livraison, total.
  3. La livraison coûte 7 TND. Elle est offerte à partir de 200 TND.
  4. Un code inconnu affiche un message rouge. La commande ne part pas tant que le code est faux.

5. Commander par WhatsApp

  1. Depuis le panier, WhatsApp ouvre une discussion avec le message déjà écrit. Cela n’enregistre pas encore la commande.
  2. Depuis la page de commande, remplir d’abord le nom, l’adresse et le téléphone.
  3. Appuyer sur Enregistrer et envoyer sur WhatsApp.
  4. La commande est enregistrée, puis WhatsApp s’ouvre avec le numéro de commande et le total.
  5. Le client doit encore appuyer sur envoyer dans WhatsApp. Rien ne part tout seul.

6. Suivre une commande

  1. En bas du site, ouvrir Suivi de commande. Le lien est aussi sur la page de confirmation.
  2. Écrire le numéro, par exemple TS-1001, et le même téléphone que lors de l’achat.
  3. Appuyer sur Suivre.
  4. Le statut s’affiche : Reçue, Confirmée, Expédiée, Livrée ou Annulée.
  5. Si le téléphone ne correspond pas, la commande n’apparaît pas.

7. Poser une question à l’assistant

  1. Appuyer sur le bouton rouge Aide, en bas à droite.
  2. Choisir Catalogue, Livraison, Code promo ou Suivi, ou écrire une question.
  3. Exemples : « robe », « livraison », « code promo », ou « TS-1001 » suivi du téléphone.
  4. Écrire sur WhatsApp ouvre la discussion. S’il y a un panier, le message contient les articles.

Ce que l’équipe fait dans l’administration

Ouvrir https://shops-25os.onrender.com/admin. Cinq onglets : Analyse, Produits, Commandes, Réglages, Assistant.

8. Lire l’activité

  1. Rester sur Analyse.
  2. En haut : chiffre d’affaires, panier moyen, commandes en cours, nombre de clients, valeur du stock, nombre d’articles.
  3. Le graphique montre les 7 derniers jours.
  4. Meilleurs articles : ce qui s’est le plus vendu.
  5. Stock faible : les articles à 5 pièces ou moins. Le bouton +10 rajoute 10 pièces tout de suite.

9. Ajouter ou corriger un article

  1. Onglet Produits.
  2. Pour un seul article : remplir Nom, Prix, Stock, Catégorie, puis Ajouter.
  3. Le rayon choisit où il apparaît sur l’accueil : Notre sélection, Meilleures ventes, ou Offres.
  4. Dans le tableau, modifier le nom, la catégorie, le prix ou le stock, puis Sauver.
  5. Supprimer retire l’article de la boutique.

10. Charger plusieurs articles d’un coup

  1. Dans Produits, descendre à Import CSV.
  2. Appuyer sur Télécharger le modèle.
  3. Remplir le fichier. La première ligne reste : nom, prix, stock, categorie.
  4. Exemple : Robe lin, 189, 8, Robes.
  5. Choisir le fichier, puis Importer.
  6. Un article qui a déjà le même nom est mis à jour (prix et stock). Les autres sont ajoutés.
  7. Exporter le catalogue télécharge la liste actuelle, utile avant une grosse modification.

11. Traiter une commande

  1. Onglet Commandes.
  2. Chercher par nom, téléphone ou numéro TS-.
  3. Filtrer par statut si besoin.
  4. Changer le statut dans la liste. Il est enregistré tout de suite.
  5. Ordre habituel : nouvelle, puis confirmée, expédiée, livrée.
  6. Annulée remet les pièces en stock. À n’utiliser que si la vente est vraiment annulée.
  7. WhatsApp client ouvre un message déjà rédigé pour prévenir le client de son statut.
  8. Exporter CSV télécharge la liste, par exemple pour un tableau de suivi.

12. Lancer une promo

  1. Onglet Réglages, partie Codes promo.
  2. Écrire un code simple, par exemple ETE10.
  3. Choisir Pourcentage ou Montant TND, puis la valeur.
  4. Appuyer sur Ajouter.
  5. Communiquer ce code aux clients. Ils le saisissent au moment de payer.
  6. Supprimer retire le code. BIENVENUE peut rester pour les nouveaux clients.

13. Régler la livraison et WhatsApp

  1. Dans Réglages, modifier les frais et le montant pour la livraison offerte.
  2. Dans WhatsApp boutique, mettre le vrai numéro, avec l’indicatif et sans espaces. Exemple : 21620123456.
  3. Appuyer sur Enregistrer.
  4. Les nouveaux messages WhatsApp de la boutique partent vers ce numéro.

14. Répondre vite à une question

  1. Onglet Assistant.
  2. Écrire le nom d’un article, « catalogue », « livraison », ou un numéro de commande avec le téléphone.
  3. La réponse reprend le stock, le prix ou le statut. C’est le même assistant que le bouton Aide du site.

Trois situations utiles en marketing

Préparer une sélection de la semaine

  1. Choisir 4 à 8 articles.
  2. Dans Produits, mettre les pièces phares en rayon Meilleures ventes ou Offres.
  3. Vérifier le stock. S’il est bas, appuyer sur +10 dans Analyse, ou corriger le nombre.
  4. Ouvrir la boutique et contrôler que les bons articles apparaissent.

Annoncer une réduction

  1. Créer le code dans Réglages.
  2. Passer une commande test avec ce code pour vérifier le nouveau total.
  3. Publier le code sur les réseaux ou dans le message WhatsApp.
  4. Le lendemain, ouvrir Analyse et Commandes pour voir ce qui est parti.

Relancer un client

  1. Ouvrir Commandes et trouver la commande.
  2. Passer le statut à confirmée, puis expédiée quand le colis part.
  3. Appuyer sur WhatsApp client et envoyer le message.
  4. Le client peut aussi suivre seul sa commande avec son numéro TS- et son téléphone.
